# 养成 / 好感度奖励 — 设计指引

> Phase 1 / Phase 4 的**可选**扩展。仅当项目给这组角色配了养成 / 好感度 / 升级系统时读本文件。
> 启用条件、与功能工程的分工见 SKILL.md「可选模块」节。

## 一、本模块产出什么

养成系统让「角色设计」多出两条**随好感度等级递进**的线,都是性格设计工作:

1. **分档立绘** —— 每角色 N 档正式立绘(典型 3 档),随好感度升级逐档解锁。
2. **分类音声台词集 + 音色** —— 一个按用途分类、按等级解锁的台词集,外加每角一种声线。

二者解决同一件事:**让「好感度涨了」这件抽象的事,变成用户看得见、听得到的角色回应。**

## 二、分档立绘(tiered portraits)

### 是什么
- 立绘 ≠ 小 idle sprite。立绘是养成详情页 / 角色卡的**大尺寸展示图**,用户主要在这里「看脸」。
- 每角色 N 档(典型 3:初遇 / 熟络 / 羁绊),好感度到阈值解锁下一档。
- 档数由功能侧的等级设计定;设计侧只要保证「每档之间有肉眼可见的递进」。

### 递进轴 —— 亲近度
一档比一档亲近。可在这些维度上推进:
- **姿态**:有距离的端坐 / 侧身 → 放松、朝向用户 → 主动凑近 / 依偎。
- **表情 · 眼神**:礼貌克制 → 自然柔和 → 卸下防备的专属表情。
- **场景 · 距离**:离镜头远、构图拘谨 → 拉近 → 占满画面的亲密构图。
- **小动作**:档位越高,越多「只对熟人才有」的怪癖外露(怪癖来自 Phase 1 档案)。

### 关键准则 —— 递进忠于性格(最容易做砸的点)
**不要让 N 个角色走同一条「挥手 → 微笑 → 拥抱」弧线。** 每个角色用**它自己的方式**变亲近:
- 高冷 / 傲娇角色的「羁绊」档,是它**克制地**流露 —— 一次罕见的软眼神、主动靠过来一点点,
  而不是突然变成抱抱狂。人设不能在最高档崩掉。
- 元气角色可以从招手 → 全身扑抱,递进幅度大。
- 胆小角色从缩在角落探头 → 敢站到画面中央。
- 每个角色在档案里写明「这一组 N 档,亲近度具体怎么涨」。

### 不变量(和普通立绘一样)
- N 档是**同一个角色**:全部复用同一段 `[ID]` 身份锚点。
- N 档都守**核心魅力**:再亲昵也别画飞。
- 剪影 / 体型在档间保持稳定 —— 变的是姿态 / 表情 / 距离,不是换一只角色。

## 三、音声台词集 + 音色

### 从 2 条台词扩成分类台词集
Phase 1 默认每角写 2 条招牌台词(自我介绍 + 品种科普)。养成系统需要一个**按用途分类、
按等级解锁**的台词集 —— 每升一级解锁一条:

| 用途(kind) | 写什么 |
|---|---|
| 问候 greeting | 见面打招呼,最先解锁 |
| 鼓励 encourage | 用户学习 / 达成时打气 |
| 升级 levelup | 好感度升级瞬间的反应 |
| 专属 special | 最高档解锁,只对「羁绊」用户说的话 |

- 条数随项目等级数定(JLPTsimu pixel_cats = 6 条 / 角色)。
- **台词和立绘同步渐进**:低档礼貌、见外;高档熟稔、亲昵、带专属感。
- 语言随项目台词约定(JLPTsimu = 日文台词 + 中文大意)。

### 音色 —— 给每个角色配一种声线
养成系统通常会给台词配语音。声线和体型一样,是**从性格推导**的设计维度:

| 性格倾向 | 声线方向 |
|---|---|
| 沉稳 / 知性 / 老练 | 低沉平稳、语速慢 |
| 高冷 / 傲娇 | 清冷、偏低、克制 |
| 元气 / 跳脱 | 明亮、偏高、语速快 |
| 慵懒 / 治愈 | 软、慢、尾音松 |
| 馋嘴 / 憨厚 | 圆润、带点含糊 |

- 设计侧产出 = **一句声线描述** +(若已选定语音引擎)记下话者 / 风格名。
- 具体引擎参数(如 VOICEVOX 的 speakerId / styleId)、商用授权标注要求,交功能工程方落地。
- 引擎无关:VOICEVOX 只是 JLPTsimu 的选择;声线匹配这步对任何 TTS 方案都一样。

## 四、落到模板的哪里

- **profile 模板**:每角档案填「🎁 养成奖励」节 —— 音色 + 音声台词集表 + 分档立绘 N 档描述。
- **生图文档模板**:多出「分档立绘」素材类目(§4.5)—— 每角 N 档,每档一行 `Subject:`,
  共用 `[ID]`;素材清单 / QA 自查相应加项。

## 五、与功能工程的分工

本 skill(themed-mascot-designer)只做**设计**:
- 立绘各档的视觉递进设计、台词文本、音色匹配。

**功能工程**交配套的 `pixel-mascot-theme` skill:
- 好感度阈值 / 解锁推导纯函数、migration、语音批量合成与托管(R2 等)、升级解锁弹窗 UI。
