# 角色形态设计原则

> Phase 3「形态设计」的核心知识库。把性格翻译成「一眼可分」的视觉形态时读本文件。

## 一、5 条核心准则(强制)

提炼自角色设计 / 像素美术 skills(见 [skill-research.md](skill-research.md)),每个主题集都适用。

1. **剪影测试** — 每个角色填成纯黑剪影,必须能立刻认出是谁;一组角色的剪影并排不能雷同。
   体型(圆 / 瘦长 / 小缩 / 塌 / 敦实)是表达性格的**第一手段**,优先于配色和细节。
2. **身份锚点(identity anchor)** — 每个角色写一段锁死的英文身份串(`[ID]`),该角色的**所有姿态/视图**的
   生图 prompt 全部带上,保证同一角色多张图是同一个。源自 character-design-sheet 的「description anchor」。
3. **姿态 > 特效** — 个性靠**体型、姿势、表情、眼神**表达,不靠飘浮装饰。
   禁止投影 / 地面影 / 光晕 / 光环 / 飘浮星星 / 速度线 —— 它们破坏透明 PNG 抠图。
   小元素(如「Zzz」)必须**贴着角色**,不能悬空。源自 hatch-pet。
4. **小尺寸先行** — 设计必须在**最终尺寸**(常是 48–128px)下还能读。细节服从剪影;
   调色板克制(主体约 16–32 色);别加在小尺寸会糊掉的微小装饰。源自 game-character-sprites 分辨率层级。
5. **表情 / 眼神拉满** — 像素小尺寸下中性脸会糊成「一个模子」。每个角色的表情和眼神必须
   **夸张化、戏剧化**,且 N 个角色之间**互不重复**。不要全画成「睁圆大眼的可爱默认脸」 ——
   这是实战中最常翻车的点(生图模型第一版定调图最容易在这里偷懒,把 N 只画成同一张脸)。
   生图文档里要为此单列一条强制要求 + QA 项;详见下方「表情 / 眼神轴」。
   源自 hatch-pet「每个 state 必须可辨」+ 像素表情可读性。
   **落地为素材**:准则 5 不止是 prompt 措辞 —— 每个角色必出一套「表情精灵集」:一张 12 态 4×3
   合集表 + 切分出的 12 张独立表情精灵(平静 / 开心 / 沮丧 / 惊讶 / 得意 / 困倦 / 加油 / 思考 / 害羞 /
   不满 / 大哭 / 欢呼)。合集表整张生成保一致,切片切好即可直接用。规格 + 12 态清单见下方
   「表情精灵集 · 12 态标准集」与 gen-prompt-doc-template.md §4.5。

## 二、性格 → 形态 映射词库

用户的原始提示:「精明的猫就瘦长;壮实的拟人肩宽;瘦弱的蜷缩畏缩」—— 把这套思路系统化:

### 体型轴(选一个主轴,一组角色要铺开,别全挤在一档)

| 性格倾向 | 体型 | 剪影关键词 |
|---|---|---|
| 馋嘴 / 憨厚 / 富足 | 极圆、大肚、重 | 接近正圆 / 布丁块 |
| 元气 / 壮实 / 热血 | 敦实、结实、有劲 | 圆 + 动态尖角(举手/前倾) |
| 高傲 / 华丽 / 蓬松 | 中等骨架被毛量/服饰撑大 | 上窄下宽梨形 |
| 精明 / 知性 / 高冷 / 老练 | 瘦长、挺拔、修长 | 竖向塔形 / 优雅 S 曲线 |
| 胆小 / 怯弱 / 内向 | 偏瘦、缩小(刻意比别人小一圈) | 含胸内收的小水滴 |
| 慵懒 / 佛系 / 治愈 | 软塌、低重心、失去骨头感 | 低矮歪斜的软团 |
| 调皮 / 跳脱 / 好奇 | 灵巧、轻盈、有弹性 | 动态对角线(动作定格) |

> 同一性格可有不同解法(如「精明」既能瘦长威严的「竖塔」,也能瘦长优雅的「S 曲线」)——
> 一组里出现两个相近性格时,**必须用不同解法拉开**(见三、避免撞型)。

### 眼神轴(每个角色一种,绝不重复 —— 见准则 5)

> ⚠️ 实战教训:生图模型很容易把一组角色全画成「同一双圆睁大眼」。眼神必须**主动拉开 + 夸张**,
> 在下列每个维度都做出差别,而不只是描述一个形容词。

- **形状**:圆睁 / 杏仁 / 细长眯缝 / 半垂下视 / 弯成开心弧 / 警觉瞪大 / 三角凶眼。
- **开合度**:全睁 ↔ 半睁 ↔ 半闭 ↔ 眯成一条缝。
- **视线方向**:平视 / 俯视 / 上瞟 / 侧瞥 / 望向远方。
- **高光**:星星高光(元气)/ 普通圆点 / 几乎无高光(高冷)。
- 参考组合:半垂俯视(高傲)· 全睁+星星(元气)· 半闭眯缝(慵懒)· 超大水汪+上瞟(胆小)·
  半眯成幸福弧(满足/馋)· 细长半闭俯视(洞察/老练)· 圆睁+坏笑(调皮)· 杏仁温和平视(知性)。

### 表情轴(每个角色一种,绝不重复 —— 见准则 5)

> 表情把性格「演」出来。一组角色并排,表情要一眼分出喜怒/冷暖,不能全是中性微笑。

冷淡无波 · 灿烂大笑(露齿)· 困倦放空 · 惊怯抿嘴 · 馋样傻笑(口水)· 凶/吼(张嘴)·
单边嘴角坏笑 · 矜持小得意 · 温柔浅笑 · 傲娇撇嘴。**宁可夸张过头,也不要平淡雷同。**

### 表情精灵集 · 12 态标准集(准则 5 的素材落点)

> 「表情轴」定每个角色的**招牌表情**(平时那张脸);这里定每个角色都要出的**12 态表情精灵集**
> —— 一张 4×3 合集表 → 切 12 张独立精灵。12 态覆盖学习 / 养成 App 的全部情绪场景。

| # | 态 | App 场景 | # | 态 | App 场景 |
|---|---|---|---|---|---|
| 0 | 😐 平静专注 | idle / 默认 | 6 | 💪 加油 / 鼓励 | 考试中打气 |
| 1 | 😄 开心 / 灿烂 | 答对、被夸 | 7 | 🤔 思考 / 疑惑 | 出题、提示 |
| 2 | 😢 沮丧 / 失落 | 答错 | 8 | 😳 害羞 / 脸红 | 高好感被撸 |
| 3 | 😲 惊讶 | 意外事件 | 9 | 😤 不满 / 鼓腮 | 被冷落、撒娇抗议 |
| 4 | 😏 得意 / 自豪 | 高分 | 10 | 😭 大哭 | 挂科、极低分 |
| 5 | 😴 困倦 | 久挂机 | 11 | 🎉 欢呼 / 庆祝 | 好感度升级 |

- **同一态、不同角色演法必须不同** —— 馋嘴角色的「开心」是口水傻笑,高傲角色是矜持上扬嘴角。
- **幅度基调全员一致**:克制型角色 12 态全部小幅(玄式),外放型全部大幅 —— 新增 6 态别和老 6 态脱节。
- 暗调 / 特殊主题可换态命名、按 App 需求增减数量,但「12 态、逐态拉开、覆盖上列场景」不变。

### 姿态轴(招牌动作 —— 一组角色不要全是「正面端坐」)

静态端坐(端庄/威严)· 动态欢呼举手(元气)· 塌坐歪靠(慵懒)· 缩肩抱尾探头(胆小)·
挺肚捧物(馋)· 入定不动(老成)· 歪头+动作定格(调皮)· 优雅侧坐(知性)。

### 五官 / 标志特征

给每个角色 1–2 个**专属辨识点**:特殊毛色斑纹、一只耳朵翘起、面罩、重点色、夸张腮帮、长胡须等。
小尺寸下靠这些「记忆点」区分。

## 三、「区别六要素」检查清单

设计一组角色时,确认这 6 项都在角色之间**拉开了差距**,不是只换配色:

1. 体型(胖瘦高矮)  2. 剪影形状  3. 眼神  4. 表情  5. 五官/标志特征  6. 招牌姿态

## 四、不可动摇的核心 —— 魅力(可爱 / 帅 / 萌,按主题定)

**差异是在「核心魅力」这个框里做的,不能为了区别牺牲魅力。**

- 若核心是「可爱」:全员锁定 chibi 大头短手短脚 + 大眼睛。瘦长的角色靠 chibi 头身比拉回可爱
  (= 「严肃的小老头」反差萌);畏缩的角色靠水汪大眼拉回可爱。
- 在每个角色档案里写明它的「**可爱锚点**」(或帅气锚点),提醒生图别画飞。
- 定调图(Phase 4)的验收第一条永远是:「8 个角色是否**全部**还守着核心魅力」。

## 五、与生图模型的配合

- **两步生成**:大画布(如 1024²)生成 → 最近邻降采样到最终尺寸,保住像素硬边。
  `magick gen.png -filter point -resize <W>x<H> final.png`
- **透明背景**:明确写 NO white box / NO drop shadow / NO floor shadow / NO glow。
- **先定调再批量**:务必先出一张「全员合集定调图」,人工确认「风格 OK + 剪影确实拉开 + 魅力没丢」,
  再批量生成。风格或体型差异一旦飘,整套返工。
